# 불량 판정소 (DEFECT JUDGE)

컨베이어로 들어오는 전극 시트를 보고 양품·불량을 빠르게 판정하는 도트 게임.

처음 하는 사람은 [튜토리얼](TUTORIAL.md) 참고 (화면 그림은 `tutorial/`). 게임 안에서는 시작 화면 왼쪽 위 「튜토리얼」 버튼으로 11장을 넘겨 봄, 처음 「게임 시작」 때 한 번 자동 표시.

## 실행
- 웹 공개: https://sseongilk.github.io/defect-judge/ (GitHub Pages, `docs/index.html`)
- PC 확인: `dist/play.html`을 브라우저로 열기
- claude.ai: `dist/index.html`을 Artifact로 게시하면 공유받은 사람끼리 공용 랭킹 사용

## 조작
- 양품: 왼쪽 버튼, 왼쪽으로 밀기, ← / A / J
- 불량: 오른쪽 버튼, 오른쪽으로 밀기, → / D / L

## 규칙
- 결함 3종: 핀홀, 미코팅, 크랙 (약 45% 확률로 섞여 들어옴)
- 8개 맞힐 때마다 스테이지 상승: 제한 시간 감소(3.4초 → 최소 1.15초), 결함 크기 축소
- 가짜 결함(양품): 스테이지 2 먼지, 3 빛 반사, 4 얼룩부터 섞임
- 틀리거나 시간 초과 시 하트 1개 감소, 3개 모두 잃으면 게임 끝
- 점수 = (100 + 남은 시간 비율 × 100) × (1 + 콤보 × 0.1, 최대 콤보 20 반영) × 피버 배수

## 재미 요소
- 피버: 10콤보마다 8장 동안 점수 2배, 모니터·시간 막대 무지개, 박자음. 틀리면 끝
- 보스 시트: 스테이지가 오를 때마다 등장. 결함 2~4개를 모니터에서 모두 터치해야 통과, 빗나간 터치는 0.4초 감소
- 반짝 시트(약 7%): 맞히면 하트 회복(가득이면 +500), 시간 정지 3초, 돋보기(3장 동안 결함 근처 표시) 중 하나
- 금색 전극(약 2.5%): 맞히면 +1000
- 반장 지시: 스테이지 2부터 가끔 「○○만 불량!」 5장 동안 지정 결함만 불량, 다른 결함은 양품
- 불량 도망: 불량을 양품으로 넘기면 도망. 3마리면 「고객 클레임」 → 반품 시트(보스 방식)
- 도감: 결함 6종, 보스·반품·금색, 아이템 3종 (12칸)
- 꾸미기: 누적 점수로 모자 색 6종·장식(리본·안경·왕관) 해금, 랭킹에 얼굴 표시
- 오늘의 판: 날짜로 정한 같은 시트 순서로 모두 겨룸, 랭킹 「오늘」 탭
- 팀: 이름·팀 화면에서 회사 조직(12개 + 무소속) 선택, 랭킹 「팀」 탭은 팀원 최고 점수 합계. 목록은 src/game.js의 TEAMS
- 채팅(웹 공개판만): 시작 화면 「채팅」, 40자·기기당 3초에 1번·최근 100개 보관, 기본 비속어는 화면에서 * 로 가림
  - 채팅 화면 3초, 그 밖에는 30초마다 새 글 확인, 안 읽은 글 수를 채팅 버튼에 표시
  - 글 삭제는 Supabase SQL로 (`delete from public.chat where id = …`)

## 이름·랭킹
- 처음 시작할 때 이름 입력(최대 8글자), 시작 화면의 「이름·팀」으로 수정
- Artifact에서는 공용 저장소 `scores/<사용자 id>` 문서 하나에 각자 최고 기록·오늘의 판 기록·팀·꾸미기 저장
  - 접근 규칙: 모두 읽기, 각자 자기 문서만 쓰기, 소유자는 모든 문서 정리 가능
  - 보기 전용(Viewer) 권한으로 공유받은 사람은 기록을 올릴 수 없음 → 참여자(Contributor) 이상으로 공유해야 함
- 웹 공개판(GitHub Pages)은 Supabase에 공용 랭킹 저장
  - 로그인 없음. 기기마다 무작위 id·비밀값을 만들어 자기 기록만 갱신, 최고 점수는 내려가지 않음
  - 설정 전이거나 연결 실패 시 이 기기 랭킹으로 동작
- 저장소를 쓸 수 없는 환경(로컬 파일)에서는 이 기기 랭킹으로 자동 전환

## Supabase 연결 (웹 공개판 공용 랭킹)
1. supabase.com에서 프로젝트 생성
2. SQL Editor에 `tools/supabase.sql` 내용을 붙여 넣고 실행
3. 프로젝트 루트에 `supabase.json` 작성 (Project Settings → API의 값, anon 키는 공개용)
   ```json
   {"url": "https://xxxx.supabase.co", "key": "anon public key"}
   ```
4. `python tools/build.py` 후 `docs/index.html` 커밋·푸시
- service_role 키는 넣지 않음
- 무료 요금제는 1주일간 접속이 없으면 일시 정지됨 → Supabase 화면에서 Restore

## 구조
- `src/game.js` : 게임 전체 (그리기, 판정, 랭킹, 입력)
- `src/page.html` : 페이지 틀 (캔버스, 이름 입력칸, 스타일)
- `tools/build.py` : 갈무리 글꼴을 필요한 글자만 잘라 넣고 `dist/`에 한 파일로 묶음
- `tools/supabase.sql` : 공용 랭킹·채팅 테이블과 저장 함수 (여러 번 실행해도 됨)
- `TUTORIAL.md`, `tutorial/` : 플레이 안내 문서와 화면 그림
- `docs/index.html` : 빌드 결과 (GitHub Pages 게시본)
- `fonts/` : 갈무리 도트 글꼴 원본 (SIL OFL 1.1, `fonts/OFL.md`, https://github.com/quiple/galmuri)

## 빌드
```
python tools/build.py
```
화면 확인용: `dist/play.html?shot=이름` (네트워크를 쓰지 않아 공용 랭킹·채팅에 기록되지 않음)
- 게임: `play` `stage` `fever` `rule`(판정 결과) `ruleon`(반장 지시 중) `boss` `gold` `escape` `over`
- 메뉴: `title` `chattitle`(채팅 버튼 표시) `name` `rank` `team` `day` `dex` `skin` `chat` `tut1`~`tut11`
- 긴 이름 확인: `long` `longtitle` `longover`
- `run`은 시간을 흘려 화면 변화 확인, `auto`는 자동으로 한 판을 끝까지 진행하고 결과를 페이지 제목에 기록

튜토리얼 그림(`tutorial/*.png`) 다시 찍기: 빌드 후 headless Chrome으로 512×896 창에서 각 화면을 찍음
- `title`←`chattitle`, `rule`←`ruleon`, 나머지는 파일 이름과 같은 shot

## 화면 표시
- 논리 해상도 128×224. 창 크기에 맞춰 소수 배율로 꽉 채우고, 세로가 긴 휴대폰은 위아래를 배경으로 늘림(최대 320줄)
- 캔버스 내부는 기기 픽셀 기준 정수 배율(최대 8)로 그려 도트 크기를 고르게 유지
- 글자는 4배 크기로 그린 뒤 각 픽셀 가운데만 읽어 도트로 찍음 (영문·작은 글씨 뭉개짐 방지)
- 판정 결과·반장 지시·보스·피버 안내는 모니터를 가리지 않게 양품·불량 버튼 바로 위 안내 줄에 표시
